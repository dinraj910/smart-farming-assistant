UI Design Document · Mobile Application

Smart Farming Assistant

Visual direction: Kerala Harvest — earthy, grounded, premium. Built for a farmer who wants clarity and calm, not another generic dashboard.

Palette

#1F4D3A · Forest

#C1662F · Terracotta

#D4A017 · Gold

#FBF7EE · Cream

#2B2621 · Ink

#E7DFCD · Line

Typography

Fraunces — headings

Warm, editorial serif. Used for titles, crop names, and hero numbers — gives the app a grown, trustworthy feel instead of a generic app-template look.

Plus Jakarta Sans — body & UI

Clean and legible at small sizes for labels, forms, and data-heavy screens.

Icon set

Custom line icons, single stroke weight, forest green — consistent across every screen, no mixed emoji.
